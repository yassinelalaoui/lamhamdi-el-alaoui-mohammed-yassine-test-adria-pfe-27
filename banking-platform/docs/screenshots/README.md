# Captures d'ecran

Cette arborescence conserve les preuves visuelles d'executions reelles.

Convention de nommage recommandee : `A1-maven-clean-install.png`, `B2-scenario-login.png`, etc. Associer chaque image a une partie, un scenario ou une commande; ne pas modifier le contenu pour simuler un resultat. Supprimer ou masquer les donnees personnelles et secrets avant de versionner une capture.

La capture [maven-clean-install.png](maven-clean-install.png) montre le resultat `BUILD SUCCESS` du build initial. Le journal de reference est decrit dans [le suivi des tests](../tests/progress-tracker.md).
